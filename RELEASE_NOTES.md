# Release notes

Sections in this file are copied into the GitHub release body, in English. A note may describe
what a user gets: a new feature, a behaviour change, a bug fix. It must not describe the code:
no file layout, no module or file names, no function names, no change detail. A release that only
reorganised code says it is a refactor with no behaviour change, and nothing more.
