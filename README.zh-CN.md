## 功能

- **命令审批**：规则表决定命令能不能跑：命中 allow 的放行，命中 ask 的挂起等你决定，命中 deny 的在
  开始前就停下。总开关可以整体关掉；没有规则、没有命中时，命令与没有这道闸门时完全一样。
- **等待中的命令有四种回答**：允许一次、本会话允许、永久允许、拒绝。选择永久允许会生成一条规则，
  在同一个页面上能看到并撤销。
- **每次被拦下都要解释**：被拦下的命令要求模型说明它做什么、为什么被拦，这段说明与决定保存在一起，
  并记入历史。
- **预置规则跟系统走**：最小集覆盖破坏性与不可逆命令，扩展集覆盖与审计相关的命令，每条按适用平台
  过滤。导入只补缺失项，你改过的规则保持原样。
- **补丁表按宿主构建分层**：每条规则列出状态：待应用、已生效、或对本构建不适用。打开规则先看它会
  改动什么，再决定是否启用。
- **改动可回退**：每个文件改动前都备份，任何一处改动都能单独或成批还原。
- **注入提示词**：操作者提示词由你自己维护的 Markdown 文件拼装，逐轮注入，并显示字符与词元规模。
- **规则集**：Markdown 规则可以写入工作区，在那里工作的代理会读到。
- **技能**：已安装的技能可以导出与导入，列表可在页面上刷新。
- **两种呈现**：面板可以整页打开，也可以在聊天旁开一个小窗；标签上显示等待审批的数量。

各版本的改动记在[CHANGELOG.zh-CN.md](CHANGELOG.zh-CN.md)。

## 安装

1. 解压归档。
2. 把解压出的目录放进你这份 DSH 的 profile 目录。
3. 把插件加入该 profile，重启一次宿主。
4. 面板从侧栏的“规范库”入口打开。

## 更新

把新包解压覆盖旧目录，重启宿主。配置与规则状态存在插件目录之外，替换后仍在。

## 卸载

从 profile 里移除插件，删除其目录，重启宿主。

## 运行要求

- Windows。
- 与本版本对应的 DeepSeek Harness 桌面端。
