# dsh-corpus

**Corpus**的发布构建，一个用于 DeepSeek Harness 桌面端的插件。

本仓库不放源码，只放构建产物、这份说明和[发布说明](RELEASE_NOTES.zh-CN.md)。

最新版本：**0.4.0**

## 下载

| 文件 |
| --- |
| `corpus-0.4.0-single.zip` |

每个版本只发一个包：单文件构建，解压即可使用。

## 它能做什么

- 维护一组补丁规则，用来调整桌面端的行为。
- 列出每条规则及状态：尚未应用、已生效、或对本构建不适用。
- 打开规则前先展示它会改动什么。
- 改动前备份每个涉及的文件，一键还原任何一处改动。
- 管理每一轮注入的操作者提示词。

## 安装

1. 解压归档。
2. 把解压出的目录放进你这份 DSH 的 profile 目录。
3. 把插件加入该 profile，重启一次宿主。
4. 面板从侧栏的“规范库”入口打开。

## 更新

把新包解压覆盖旧目录，重启宿主。配置与规则状态存在插件目录之外，替换后仍在。

## 卸载

从 profile 里移除插件，删除其目录，重启宿主。

## 运行要求

- Windows。
- 与本版本对应的 DeepSeek Harness 桌面端。
